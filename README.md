# Python-Projects

***Python Concepts Used for QUIZE APPLICATION**

1. **Variables**: Store the score, user answers, and percentage.

2. **Lists**: Store multiple questions and answer options.

3. **Dictionaries**: Store each question, its options, and the correct answer.

4. **Functions**: Organize the program using the run_quiz() function.

5. **Loops**: Iterate through questions and options using for loops.

6. **Conditional Statements**: Use if, elif, and else to check answers and provide feedback.

7. **User Input**: Use input() to accept answers from the user.

8. **Input Validation**: Use a while loop to ensure the user enters a valid option.

9. **String Methods**: Use strip() and upper() to handle user input consistently.

10. **Arithmetic Operators**: Calculate the score, wrong answers, and percentage.

11. **Built-in Functions**: Use len() to count questions.
    


***Python Concepts Used for Rock_Paper and Scissors game**

1. **Variables**: Store the player's choice, computer's choice, and game results.

2. **User Input**: Uses input() to accept the player's selection.

3. **Conditional Statements**: Uses if, elif, and else to determine the game result.

4. **Random Module**: Uses random.choice() to select Rock, Paper, or Scissors randomly.

5. **Lists**: Stores the available choices in a list.

6. **Loops** : Allows the game to repeat for multiple rounds.

7. **String Methods**: Uses lower() or strip() to handle user input consistently.

8. **Comparison Operators**: Compares the player's choice with the computer's choice.

9. **Logical Operators**: Combines conditions to identify winning situations.

10. **Counters** : Tracks scores across multiple rounds.
